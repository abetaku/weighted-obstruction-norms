# 第7回：原始元最小化と原稿の極限公式

- `CechPrimitive.split` / `join`：全コチェインと旧・新のブロック座標の相互逆対応。
- `split_norm`：この対応が原稿の重み付き最大ノルムを正確に保存すること。
- `split_feasible`：原稿の方程式 δx=jc とブロック最適化の制約の同値。
- `cost_eq_gamma`：全コチェイン上で直接定義した原始元最小値と、一般線形問題の `gamma` の一致。
- `CechReciprocal.primitive_reciprocal`：q₀の正の支持がS、q₁が全状態で正という条件の下で、アフィン混合の原始元最小値について、非零類の厳密な逆比例則。
- `CechReciprocal.norm_limit`：ゼロ類を含む全類で、εΓεの右側極限が具体的H^p(C_S)上の障害ノルムに等しいこと。
- `CechObstruction.Normed`：元のČechコホモロジーの参照法則別の型コピーに、NormedAddCommGroup、NormedSpace ℝ、FiniteDimensional ℝを構成。

正の基準法則q₁を積法則とする仮定はありません。q₀の正の値そのものは障害ノルムの定義に現れません。原始元次数の添字pは原稿のp−1に対応し、p=0は第5回のaugmentationEquivで原稿の大域測度空間と同定される空添字空間です。

これにより、第6回で残していた「モデルの最小化と原稿の原始元最小化の同一性」を解消しました。原稿の全体は未完了です。高次数の観測制限とホモトピー・リスト不変性・関手、中心対称多面体、具体例の全次数フロントエンドへの型付き同定、付録の順序複体比較を残しています。
