# 第4回の追加成果

Lean 4.19.0 / 固定mathlibコミットで、全207件の名前付きtheorem/lemmaのビルドと公理依存検査が成功しました。前回155件から52件追加しています。宣言数は補助補題を含み、論文の定理数ではありません。

## 具体的な有限観測とČech複体

`FiniteObservations.lean` では有限積状態、観測部分集合への射影、支持の射影、射影支持間の制限、支持拡大を型として構成しました。局所符号付き測度の周辺化は有限押し出しとして定義しています。合成則、支持拡大の単射性と周辺化との可換性、全支持参照重みの正値性、実際の周辺重みによる非拡大性を証明しました。

`CechLowDegrees.lean` は、原稿と同じ厳密な昇順の組・三つ組で次数−1,0,1,2を構成しています。増大写像と二つの微分を実際の周辺化から定義し、δ⁰δ⁻¹=0とδ¹δ⁰=0を証明しました。H⁰・H¹をコサイクル／境界の商として構成し、支持拡大が誘導する写像も定義しています。平方零条件を仮定する抽象モデルではありません。

ただし全次数の複体、全支持での非輪状性、一般の相対座標分割との同定は未完了です。

## 次数0の観測変更

`ObservationRestriction0.lean` は任意の選択fによる観測制限を実際の周辺化から定義しています。閉性の保持、増大写像との可換性、H⁰への降下、選択独立性、恒等・合成則、支持拡大との可換性を証明しました。

同じ下降閉観測族を生成するリストの間には、選択写像を構成し、具体的H⁰の線形同型を得ています（`generated_H0_equiv`）。ここでは線形同型を証明しており、具体的H⁰の障害ノルムとの同定と等長性は残っています。高次数の観測制限・反復添字の符号処理・明示的ホモトピーも未完了です。

## 窓写像とノルム比較

`WindowMap.lean` は、支持拡大で新座標が旧座標になる際の補正項を含む窓写像を定義します。コホモロジー写像を商から構成し、接続写像の自然性、実行可能集合の保存、座標非拡大性からの障害ノルム比較を証明しています。

また、恒等・合成、与えられたホモトピーからのコホモロジー写像の一致、実際の連続線形縮小写像、両方向の座標非拡大性と逆写像条件の下での線形等長同型を構成しています。具体的な全次数Čech複体がこれらの入力条件を満たすという部分は未完了です。
