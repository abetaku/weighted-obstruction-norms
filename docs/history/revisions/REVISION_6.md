# 第6回：全支持非輪状性と具体的相対窓

補題2.1を、既存の昇順添字・射影支持・実際の周辺化から構成した全次数Čech複体で証明しました。

- `SimplexContraction`：最小頂点挿入による原始元。空の頂点集合も含めて全次数に対応。
- `InteractionCoordinates`：基準点に全質量を集める有限積の座標変換、明示的逆変換、線形同型、周辺化との可換性。
- `FullSupportAcyclicity`：各相互作用座標の単体成分への分解と再構成、原始元の存在、元の `CechAllDegrees.Cohomology` の零性。
- `CechSplitting`：旧支持座標と補集合座標の分割。`RelativeWindow` の完全性は今回の非輪状性から証明し、窓のコホモロジーを元のČechコホモロジーに線形同定。
- `CechObstruction`：具体的な周辺参照重みによる障害ノルム、非退化性・三角不等式・絶対斉次性・単位球公式・接続全射。状態法則の比較から命題5.4の不等式を全次数で証明。
- `CechSupportNorm`：支持拡大の具体的窓写像、旧座標へ移る成分の補正、元のコホモロジー写像との一致、命題3.3の全次数非拡大性。
- `CechRelative`：実際の前段微分と完全性。p≥1の相対接続同型と値の保存、p=0の追加商の同型と値の保存。

基準点 `o : ∀ i, E i` は原稿の各有限状態空間の非空性に対応します。独立な確率法則や積法則は仮定しません。空の観測交差や空の観測リストを除外していません。

全論文の完了ではありません。原始元の重み付き最小値と具体的ブロック最適化の同一性、観測変更の障害ノルム比較と高次数ホモトピー、中心対称多面体、具体例と全次数実装の同定、付録の順序複体比較が残ります。正確な検証件数と依存公理は `audit/verification.json` と `audit/axioms.log` を参照してください。
