# 第10回：付録の順序複体比較

この改訂では付録A.1と付随する補助主張を実装しました。論文全体としては、二値例の専用有限座標表示と一般実装の型付き接続が残ります。

基礎の昇順タプルを半順序の鎖へ一般化しました。全順序上の元のČech複体は同じ定義・証明の特殊例として保たれます。全支持の相互作用分解は、各成分の鎖複体の完全性へ還元する形に分離しました。元のČech複体では有限全順序の最小頂点を、順序複体では相互作用支持そのものを最小元として挿入することで、その完全性を実証します。

- `OrderComplex`：包含鎖の複体、原稿の微分公式、平方零性、全支持非輪状性。
- `OrderObstruction`：実際のコホモロジー上の障害ノルム、ノルム空間構造、原始元最小値の再尺度化極限。
- `OrderRestriction` / `OrderRestrictionNorm`：全次数の比較写像、微分・支持拡大との可換性、コチェインと障害ノルムの非拡大性。
- `OrderComparison`：包含関係を延長する全順序を使用し、Rが文字どおり鎖への制限になることを証明。増大次数の恒等性と、原始元次数−1・0の線形同型・ノルム保存も構成。
- `OrderLowZero`：包含整合性と交わり整合性の同値からH⁰同型を構成し、実際のRとの一致を証明。
- `OrderLowOneInjective`：閉Čech 1コチェインが包含対上の値で決まること、原始元最小値と障害ノルムの一致。
- `OrderLowOneInverse`：原稿の交わりによる逆公式を直接実装。等しい端点をゼロで補い、鎖のコサイクル式、復元したČechコサイクル、両側の逆性、境界部分空間の対応を証明。
- `OrderPrimitiveComparison`：原始元の対応が重み付きノルムを保存するとき、実際の最小値が一致し、極限でも障害ノルムが一致することを証明。
- `OrderLowIsometry`：次数0・1の実際の `LinearIsometryEquiv` と、任意の生成リストへの移行。

次数2以上では原稿どおり非拡大性のみを主張しています。代数的比較から高次数の逆ノルム不等式を推論していません。
