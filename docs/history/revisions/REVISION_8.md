# 第8回：観測制限、選択ホモトピー、多面体単位球、関手

この改訂でも原稿全体の形式化は未完了です。主な追加は次のとおりです。

- `SlicePolytope`：箱と部分空間の切り口の有限極点性、有限凸包表示、線形像への移行。
- `CechPolytope`：元のČechコホモロジーの障害単位球の有限凸包表示と中心対称性。
- `AlternatingEvaluation`：行列式で定義した交代拡張、置換符号、重複消去、微分との可換性、任意写像に沿う引き戻し。
- `ObservationRestriction`：実際の周辺化を用いた全次数制限写像。微分・支持拡大との可換性、恒等・合成則、元のコホモロジーへの降下。
- `ListPrism`、`PrismEvaluation`：明示的なプリズム、境界恒等式、固定次数の交代コチェインとの双対化、係数と頂点写像に関する自然性。
- `ObservationHomotopy`：元の周辺複体上の選択ホモトピーと、全次数のコホモロジー写像の選択独立性。
- `ObservationRestrictionNorm`：実際のコチェインノルムと障害ノルムの非拡大性。相対新座標が旧座標へ移る場合の補正を含めて証明。
- `ObservationListInvariance`：生成観測族が等しいときの全次数の線形等長同型。
- `FiniteNormedCategory`、`ObservationFunctor`：支持と下降閉観測族の圏、固定順序の極大観測リスト、有限次元実ノルム空間と線形非拡大写像の圏、実際の関手。

監査スクリプトは、同じ行に属性が付いた `@[simp] lemma` と `Hom.ext` のようなドット付き宣言名も収集するよう更新しました。追加した補助補題を含めて、名前付き定理・補題の推移的公理依存を検査します。検証結果の正確な件数・ソースハッシュは `audit/verification.json` に記録します。

残作業は二値例と一般実装の型付き接続、三角形のコホモロジー類と係数の同定、付録の順序複体比較です。増大次数の表示補題、相対側の等長同型の再パッケージも対応表に残しています。
