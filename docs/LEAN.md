添付論文の全14件の定理・補題・系・命題を、付録と二値例の具体的な接続を含めて形式化しました。**640個の定理・補題と主要5定義を検証対象**とし、証明穴や独自公理は使っていません。全体の対応は `FORMALIZATION_STATUS.md`、宣言名の対応表は `audit/paper_coverage.json`、最終検証記録は `audit/verification.json` を参照してください。

Lean 4.19.0 と固定mathlibコミットを使います。実装は標準的な古典数学に基づく証明ライブラリです。原稿の動機・引用・将来課題の文章を証明命題にするものではありません。

## 検証した主な内容

- 有限座標の重み付き最大ノルム。空の座標集合も許す。
- 非空な閉集合上の最小値の存在。有限次元の有界閉区間のコンパクト性から証明。
- 実際の最適化問題の下限として定義した `coefficient` と `gamma`。
- 障害係数がゼロであることと、旧座標だけで解が存在することの同値。
- **正の障害係数に対するアフィン混合の厳密な逆比例則**。旧座標の傾きは負でもよく、小さい正のパラメータに対する閾値を証明中で構成。
- **共通消失スケールでの再尺度化極限**。新座標の重みが正確に比例する場合の最終的な等式も証明。
- **双対公式と最大値達成**。重み付きℓ¹制約を持つ原稿の双対問題を定義し、弱双対性・最大化解の構成・上限表示を証明。Hahn–Banachには固定mathlibの定理を使用。
- **ゼロ障害時の非尺度化極限**。新しい重みが座標ごとにゼロへ収束すればよく、共通消失スケールは不要。必要な旧座標補正写像は証明中で構成。
- **分裂した複体の一つの次数範囲に対する接続**。旧コホモロジーを実際の「コサイクル／境界」の商として定義し、相対コサイクル上の接続写像の全射性、最小化制約の同一性、単位球公式、ノルムの公理、非零類の逆比例則を証明。
- **相対コホモロジーへの降下と追加商**。前段の微分を加え、相対境界で割った接続写像を構成。接続核が全体のコホモロジーの像であること、前段完全性の下での同型、一般の場合の核による追加商、独立に定義した最小値の保存、二段階最小化の一致と達成を証明。
- **有限次元ノルム空間のインスタンス**。重みごとの型コピーに障害ノルムを入れ、Leanの `NormedAddCommGroup`、`NormedSpace`、`FiniteDimensional` として構成。
- 一般の全射線形写像を通す最小ノルムの非退化性、三角不等式、絶対斉次性、単位球の像の公式、参照重みの比較。
- **複体間の写像とノルム比較**。`WindowMap` で補正項を含む写像からコホモロジー写像、接続自然性、恒等・合成則、ホモトピーによる写像の一致、連続線形縮小写像、逆写像がある場合の線形等長同型を構成。
- **具体的な有限観測と低次数Čech複体**。有限積状態と支持の射影、重み、周辺化、支持拡大を構成。昇順添字で次数−1,0,1,2の微分と二つの平方零性、H⁰・H¹およびその支持拡大写像を証明。
- **次数0の観測制限**。具体的H⁰写像の選択独立性・恒等・合成則・支持拡大との可換性、同じ下降閉観測族を生成するリストのH⁰線形同型を証明。全次数での障害ノルムの等長性は第8回で追加。
- 有限写像による符号付き測度の押し出し、合成則、単射に沿う拡張の単射性、重み付きノルムの非拡大性。
- 与えられた収縮・ホモトピーから得られる代数的補題、接続代表の持ち上げ独立性、閉持ち上げによる核の特徴づけ。
- **対角支持の例のコホモロジー計算**。二座標最適化に加え、二値状態からの押し出しと周辺化行列の一致、窓の完全性、H^0の一次元性、生成元の非零性、接続写像の対角線の核、`N(a[c])=2|a|`、単位球と全 `0<ε≤1` での原始元最小値 `2/ε` を証明。
- **三角形の12実変数・6周辺方程式に対する正確な閾値** `max(1, 2/(3ε))`。全ての `0<ε≤1` を対象に、任意の実数の解に対する下界と明示的な達成解を証明。有限個の ε の計算実験ではない。

- **全次数のČech複体**。昇順の順序埋め込みを添字とし、面削除と実際の周辺化の交代和から微分を構成。任意の次数でδ²=0を証明。空添字空間をℝ^Sに同定し、最初の微分が周辺化の族になることを確認。
- **全次数の支持拡大とコチェインノルム**。全次数のコホモロジー、有限次元性、支持拡大写像と恒等・合成則を構成。支持拡大による重み付きコチェインノルムの保存も証明。

- **原稿の原始元最小値への接続**。第7回で全コチェインとブロック座標の双方向対応、重み付きノルムと制約の一致を証明。元の最小値について、非零類の厳密な逆比例則と、ゼロ類を含むεΓεの右側極限を証明。具体的Čechコホモロジーにノルム空間のインスタンスも構成。

- **中心対称多面体の単位球**。重み付き箱と部分空間の切り口が有限個の極点の凸包となることを証明し、具体的な障害ノルムの単位球へ適用。
- **全次数の観測制限と選択ホモトピー**。任意の頂点選択、重複・順序逆転、実際の周辺化、支持拡大との可換性と障害ノルム非拡大性を証明。
- **生成リスト不変性と関手**。全次数の `LinearIsometryEquiv` と、支持・観測族の圏から有限次元実ノルム空間・線形非拡大写像の圏への実際の関手を構成。

- **付録の順序複体比較**。包含鎖の微分と全支持非輪状性、障害ノルムと原始元極限、Rの全次数非拡大性、次数0・1の明示的なコホモロジー同型と原始元最小値の一致を証明。`OrderLowIsometry` で実際の線形等長同型にまとめました。

## 完了した最終接続

- `TriangleCost.cost_eq` は一般Čech複体上の最小値 max(1,2/(3ε)) を、`TriangleNorm.obstruction_norm` は実際の非零類のノルム2/3を与えます。
- `DiagonalCost.cost_eq` と `DiagonalNorm.norm_multiple` は原始元最小値2/εと障害ノルム2 abs(a)を与えます。
- `DiagonalSpanning.generatorEquiv` は実際のH⁰とℝの線形同型です。`cohomology_dimension` と `unit_ball` は一次元性と単位球全体を記述します。
- `DiagonalConnecting.connecting_coordinates` と `connecting_kernel` は実際の相対座標で接続写像とその核を同定します。`DiagonalRelativeCoordinates` は座標の単射性、相対複体の集中次数、参照重み、核の測度による実現、相対コホモロジー上の核まで証明します。
- `SmallObservationLists` は、観測を減らした場合の障害群の消滅を一般の支持について証明します。

## この実行環境に限った起動補助

本実行環境では `/proc/<自プロセスID>/exe` が存在せず、標準の `/proc/self/exe` は読めました。Leanの実行ファイル位置取得を可能にするため、同じ自プロセスを表す後者のパスへ読み替える補助ライブラリを利用しました。Lean本体・カーネル・mathlibの証明ソースは変更していません。

補助のソースは `audit/lean_proc_compat.c`、実行内容は `audit/environment.md` に記録しています。通常のLinux/macOS/Windows環境での再検証にはこの補助は不要です。厳密な独立再現には、通常のLean環境で上の検証スクリプトを実行してください。
